# @crypto/patch-notes

Versioned patch notes package for the Crypto Calc monorepo.

## Structure

- `versions/vX.Y.Z/PATCH_NOTES.md` — release notes for a specific version
- `versions/vX.Y.Z/NEXT_UPDATE.md` — queued follow-up items for that version cycle

## Current Versions

- `v1.2.0`

## Usage

Add a new folder under `versions/` when preparing a release, then copy/update:

- `PATCH_NOTES.md`
- `NEXT_UPDATE.md`
